# 小鹅通课程目录搬到视频右侧

<img src="assets/logo-128.png" width="96" height="96" alt="小鹅通课程目录 Logo">

把小鹅通课程目录放到视频右侧，支持全屏搜索、切课、可拖动小猫和桌面悬浮。

当前版本：**1.10.4** · [MIT 许可证](LICENSE) · [更新记录](CHANGELOG.md)

## 安装

1. 在桌面版 Chrome 中安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 打开 [GreasyFork 脚本页面](https://greasyfork.org/zh-CN/scripts/600209)，点击安装，按油猴提示完成。
3. 刷新小鹅通课程学习页。

也可以从 [GitHub 直接安装脚本](https://raw.githubusercontent.com/joeljhou/xiaoe-catalog-right/main/xiaoe-catalog-right.user.js)。只启用一份同名脚本，避免重复执行。

## 功能与操作

- **网页内嵌**：目录默认位于视频右侧，高度自动与完整播放器底边对齐，最高 800px；窄页面自动排在视频下方。
- **全屏目录**：右上角保留「课程目录」入口，展开后铺满视口高度，支持搜索和切课。
- **左右调宽**：拖动左右边缘，最高宽度 640px；顶部、底部和四角不支持缩放。
- **拖动与嵌回**：拖动标题栏可让目录在页面内悬浮，点击「嵌回网页」或双击标题栏恢复内嵌。
- **小猫模式**：点击「收起」变成捧书小猫，可在页面内自由拖动，点击展开。
- **桌面悬浮**：点击「桌面悬浮」，再拖动独立窗口的系统标题栏，可以把目录或小猫放到浏览器外的桌面上。
- **播放偏好**：记忆清晰度与倍速；「当前学习」徽标高度为 18px。

## 桌面悬浮说明

桌面悬浮使用 Chrome 的 Document Picture-in-Picture，需要支持该 API 的新版桌面 Chrome。窗口的系统标题栏、边框和最小尺寸由 Chrome 管理；移动窗口需要拖动系统标题栏。脚本内的目录内容上限为 640×800px。

原课程标签页刷新、整页跳转或关闭时，Chrome 会关闭桌面窗口；整页刷新也会退出全屏。脚本无法创建透明无边框的原生桌宠。

## 隐私与配置

搜索沿用小鹅通原站接口，播放偏好保存在浏览器本地。脚本不添加统计或数据上传。

可在脚本顶部的 `CONF` 中修改默认宽度和尺寸上限。Logo 为原创 SVG，`assets/` 中包含源文件和 16、32、64、128、512px PNG；脚本用 `@icon` 内嵌 64px PNG，无需外部图片请求。

## 验证

```sh
node --check xiaoe-catalog-right.user.js
```

1.10.3 的本地模拟页面通过 64 项检查，覆盖仅左右调宽、自动高度、嵌回网页、全屏入口、切课与播放器回归。1.10.4 增加 Logo 和许可证元数据，运行逻辑沿用 1.10.3。模拟页面验证不能替代所有真实课程页的兼容性测试。
