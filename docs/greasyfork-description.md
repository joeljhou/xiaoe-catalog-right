把小鹅通课程目录移到视频右侧，边看边查课、切课。

### 使用效果

![使用前后对比](https://raw.githubusercontent.com/joeljhou/xiaoe-catalog-right/main/docs/images/before-after.png)

### 功能

- **网页内嵌目录**：默认与播放器左右排列，高度自动对齐播放器底边，窄页面排列在视频下方。
- **全屏课程目录**：右上角常驻入口，支持展开、收起、搜索和切课，目录铺满全屏高度。
- **柔和章节配色**：用不同浅色区分章节，展开的课时使用同色系更浅底色和细分隔线，当前学习仍为蓝色高亮。搜索和排序后颜色保持一致。
- **左右调宽**：最高 640px，双击边缘恢复默认；不支持上下和四角缩放。
- **右下角小猫**：收起目录后显示小猫，全屏时避开控制条。页面内可拖动，点击展开目录。
- **播放偏好**：记忆并尝试恢复清晰度与倍速。

### 安装

1. 在桌面版 Chrome 安装 Tampermonkey 等用户脚本管理器。
2. 安装本脚本，刷新小鹅通电脑端课程学习页。
3. 全屏时点击右上角「课程目录」，收起后点击小猫展开。

本版已移除桌面悬浮、嵌回网页和拖动目录标题栏的功能，目录留在当前网页内。

### 说明

适用于小鹅通电脑端课程学习页，需登录并拥有对应课程权限。普通页面目录最高 800px，全屏以视口高度为准。整页刷新会退出全屏，网站改版可能影响兼容性。

脚本不添加第三方统计或数据上传，播放偏好保存在浏览器本地，搜索沿用原站功能。
