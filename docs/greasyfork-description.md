把小鹅通课程目录移到视频旁，可选择左侧或右侧，边看边查课、切课。

### 使用效果

![使用前后对比](https://raw.githubusercontent.com/joeljhou/xiaoe-catalog-right/main/docs/images/before-after.png)

### 功能

- **自选左右位置**：标题栏提供左侧／右侧目录图标，选中位置以蓝色高亮，悬停显示文字说明；默认右侧，自动记忆同一站点内的选择，全屏沿用。窄页面仍放在视频下方。
- **网页内嵌目录**：默认与播放器左右排列，高度自动对齐播放器底边，窄页面排列在视频下方。
- **同侧收起与展开**：点击标题栏收起图标后，播放器同侧边缘显示蓝色「课程目录」竖标签，点击原侧标签恢复，保留搜索、滚动和宽度。普通页面随播放器滚动，全屏贴同侧屏幕边缘。
- **全屏目录**：支持搜索和切课，目录铺满全屏高度。
- **柔和章节配色**：用不同浅色区分章节，展开的课时使用同色系更浅底色和细分隔线，当前学习仍为蓝色高亮。搜索和排序后颜色保持一致。
- **左右调宽**：最高 640px，双击边缘恢复默认；不支持上下和四角缩放。
- **播放偏好**：记忆并尝试恢复清晰度与倍速。

### 安装

1. 在桌面版 Chrome 安装 Tampermonkey 等用户脚本管理器。
2. 安装本脚本，刷新小鹅通电脑端课程学习页。
3. 点击标题栏的收起图标，再点击播放器同侧的「课程目录」标签展开。

本版已移除小猫、右上角重复入口、桌面悬浮、嵌回网页和拖动目录标题栏的功能，目录留在当前网页内。

### 说明

默认适用于 `*.pc.xiaoe-tech.com` 的电脑端课程学习页，需登录并拥有对应课程权限。自定义域名课程需在油猴脚本设置的「用户匹配」中添加具体课程域名规则。普通页面目录最高 800px，全屏以视口高度为准。整页刷新会退出全屏，网站改版可能影响兼容性。

独立课时链接可能不含课程集合上下文，原站没有目录时脚本保持页面原样。需要完整目录，可从「包含该课程的还有」进入课程集合，再点「继续学习」。

脚本不添加第三方统计或数据上传，目录位置与播放偏好保存在浏览器本地，搜索沿用原站功能。
